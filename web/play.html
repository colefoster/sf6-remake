    what this is

    Every box, every frame length and every outcome comes from the game's own dumped tables. The page runs the same Match the CLI does — it is not a re-implementation. Hurtboxes are blue, hitboxes red, pushboxes purple — the same palette the box viewer uses, because both pages draw through the same renderer.
